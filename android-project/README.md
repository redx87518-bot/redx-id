# Redx ID Card Generator

> **For Educational Purposes Only**

A Kotlin Android app that generates Pakistan CNIC and Nigeria NIN card previews by overlaying user-supplied name, date of birth, and photo onto official card templates.

## Features

- 🇵🇰 Pakistan National Identity Card (CNIC) generator
- 🇳🇬 Nigeria NIN Digital Slip generator
- Custom name, date of birth, and photo overlay
- Save to gallery or share

## Build

```bash
./gradlew assembleDebug
```

APK output: `app/build/outputs/apk/debug/app-debug.apk`

## GitHub Actions

Every push to `main` automatically builds the APK. Download from the **Actions** tab → latest workflow run → **Artifacts**.
